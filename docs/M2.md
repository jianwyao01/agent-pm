# M2：detect + plan + scope + probe

M2 实现工作区画像、人类可编辑的运行计划，以及首发探测范围。  
它**不是**启动产品，也不是 Discovery / Agent。

> 产品级 Rocket.Chat 证明是**后续**在操作者机器上对真实工作区的可信运行，**不是 CI**。  
> CI 使用通用多组件夹具（Meteor 形状的应用 + docker-compose mongo）。M3 才实现 `start`。

## 范围内

- `ProjectAdapter.detect(workspace) -> ProjectProfile`  
  通用读取：`package.json`、docker-compose、`meteor` / `.meteor`、mongo / redis 线索、README 启动提示。  
  **禁止**硬编码「若仓库是某产品则…」。
- `ProjectProfile` 用 **faces / parts / frameworks / how_to_run** 描述，不用单一 `projectType` 枚举做主键。
- `ProjectAdapter.createRunPlan(workspace, profile) -> RunPlan`  
  人类可编辑 YAML。当线索存在时至少命名 **app + database**，以及其它已声明服务。
- 每个组件：`id`、`role`、`depends_on`、`install`、`start_order`、**自己的** `healthcheck`、`logs`。  
  Healthcheck **不是**独立组件。  
  仅当工作区需要种子时写入 seed；否则 `seed.status: not_done`，不编造。
- 密钥只允许 `secret_ref`。`password` / `token` 明文使 schema / 校验失败。
- 「一条启动命令 + 一个健康检查 URL」的扁平计划无效，由校验器拒绝。
- `confirmation: { status: draft | confirmed, confirmed_at? }`。  
  将来 `start()` **只读** confirmed 的 `run-plan.yaml`。  
  助手函数 `assertPlanConfirmed(plan)`：draft 拒绝，confirmed 通过。M2 **不实现** start。
- 确定写入（无 Agent）：
  - `study.yaml`：`id` / `name` / `goal` / `entry_seeds` / `include_hints` / `exclude_hints` / `exploration_mode: approved_probe`
  - `probe-plan.yaml`：entry、session slot、目标 Surface、send action、其它要刷新的 Surface（M4 将执行此形状）
  - `run-context.yaml`：role / locale / flags / `credential_ref` / `cookie_ref` / entry URL

## 范围外（禁止在 M2 实现）

- `start` / `stop` 的真实实现（接口保留，返回 `not_shipped` / implementation not shipped，同 Source.archive）
- Discovery runtime、真实 LLM Agent
- Effect DAG / platform / Broker
- 克隆 `https://github.com/RocketChat/Rocket.Chat` 或任何真实产品仓库

## 首发 study

领域：**消息发送与状态同步**。

- 范围内：打开已有目标 Surface 并发送一条消息，包括打开该 Surface 的导航树点击。发送入口**不得**标为范围外。
- 范围外：穷尽导航树、创建容器、容器管理、穷尽私信、话题串、管理后台。
- 核心类型永远是 Surface / Control / Journey / Observation。  
  不得把 Room / Channel / Rocket.Chat 当作类型。产品名只允许出现在注释 / 文档 / 夹具的示例 locator。

## start / stop

接口存在于 `ProjectAdapter`。  
M2 实现必须表明 **implementation not shipped**，而不是「系统没有 start」。  
M3 实现 start；start 将先调用 `assertPlanConfirmed`。
