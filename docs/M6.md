# M6：人工审定模型与四份导出

M6 把**人类审定**写成唯一规范语义模型，并由四个**导出函数**消费同一份已接受旅程列表。  
它不是 Effect DAG / Broker / Scheduler，也不是可写 Web 编辑器或外部 Agent API。

> 夹具闭环先闭合首发类型（入口、发送控件、一条已接受发送旅程、跨面效果）。  
> 产品级 Rocket.Chat 证明（真实 RC 发送上的 MAP）是**后续**在操作者 Linux 机器上的可信运行，**不是 CI**。  
> 本里程碑不声称目标应用 CI 变绿。

## 锁定契约

人工审定写入 `analysis/model/`，这是**唯一**规范语义模型：

- `capabilities.yaml`
- `journeys.yaml`
- `effects.yaml`
- `review-decisions.yaml`

人类可以 **rename / keep / reject**，并**补录一条**其认为有效的旅程。  
`journey_id` 在人类接受时分配；此后稳定，重命名不改 id。  
新 run **不得**覆盖 `model/` 里已有的 keep / reject / rename。

## 新 run 与 diff

新 run 写入新的 `runs/<run-id>/`，且**必须**写 `diff.json`：

- `baseline_run_id`
- `current_run_id`
- `comparison_mode`: `same_snapshot` | `changed_snapshot`

默认基线 = 同一 study + 同一 scope 的上一完成 run。  
其它基线**只能**通过显式命令参数（`--baseline`）。  
旧模型里本 run 未再观察到的项标为 `stale` | `not_observed`，禁止静默删除。  
新提案出现在 `diff.json` 的 `new_proposals`，不得据此偷偷改写 model 决策。

## 导出是函数，不是第五套接口

四个函数消费同一份已审定旅程列表，同一稳定 `journey_id`：

- `generateProductMap(model)`
- `generateDiagrams(model)`
- `generateWeb(model)`
- `generateTests(model)`

Web 不是更高权威。

### 产出

- 产品地图：工具说明用中文；目标界面原文保持原语言
- Mermaid 图
- 只读离线 Web（无网可打开，不加载外部 URL）
- Playwright 形状的草稿：合法 TypeScript，可被 Playwright 发现，每条测试含 Journey ID。不可靠 locator → `test.skip` 或 TODO。不声称这些测试已对目标应用通过

## 首发领域地图

仓库文档**没有**预先规定 MAP-1..MAP-8 编号。本里程碑的首发地图是：

- 入口（已有目标面 / 导航打开）
- 发送控件
- 一条已接受的发送旅程
- 跨面效果：本面 / **他面** / 列表 / 未读 / 通知 / 后台  
  未读与通知允许「未观察到」；永不省略他面

## 范围外（禁止在 M6 实现）

- Effect DAG / Reconciler / Broker / Scheduler / 外部 Agent API
- 可写 Web 编辑器
- 克隆 `https://github.com/RocketChat/Rocket.Chat` 或任何真实产品仓库
- 把 Room / Channel / Rocket.Chat 当作核心类型
- 声称目标应用 CI 变绿
