# M4：Discovery scan / explore / execute + 一次 Probe 发送

M4 实现 `DiscoveryAdapter.scan` / `explore` / `execute`，以及一次由人类确认的 probe 驱动的发送。  
观察只存**通用**类型，不存产品六列。这不是真实 LLM Agent（M5），也不是人工审定模型与四份导出（M6）。

> CI 使用仓库内的**双 Surface 微型夹具**（列表 + 撰写/详情），**不**克隆真实产品仓库。  
> 产品级 Rocket.Chat 发送是**后续**在操作者 Linux 机器上、用户将该仓库标为 trusted 并提供会话之后的可信运行，**不是 CI**。  
> 不要声称给自己发送时未读或通知一定出现。

## 锁定契约

- `DiscoveryAdapter.scan(workspace, scope) -> StaticDiscoveryResult`
  - **不**依赖 `StartResult` 或 `RunningProject`。start 失败后测试仍必须能调用 scan。
  - `scope` 是 study.yaml 的提示（`entry_seeds` / `include_hints` / `exclude_hints`），不是核心里的硬编码业务词。
  - 每一个发现的候选都写入 `candidates.jsonl`。禁止 Top-N，禁止静默丢弃。
  - 若碰到资源上限：`status=partial` + 明确的 `Gap`。
- `DiscoveryAdapter.explore(project, context, scope) -> RuntimeDiscoveryResult`
- `DiscoveryAdapter.execute(project, context, action) -> ActionObservation`
  - 仅当 start `status === success` 时使用 `RunningProject`。
  - Web phase-1：驱动 click / type / submit（Playwright）。
  - scan 若看到 swipe / long-press：保留候选，`execution_status=not_executed`。
  - 真实发送**只**由人类确认的 `probe-plan.yaml` 驱动（`exploration_mode: approved_probe`）。不闲逛。不让 Agent 追加 probe。

## 观察

只存通用类型：

- `current_surface` / `other_surface` / `collection` / `indicator` / `notification` / `backend_operation`

六列展示（本面 / **他面** / 列表 / 未读 / 通知 / 后台）是投影，不是存储模型。  
`displayObservations` 把通用观察映射到这六列；缺的填「未观察到」。永不省略他面。  
未读 / 通知不必实际发生。

- 若看到实时推送则记录；否则刷新他面并记录增量。不解析 websocket 协议。
- 后台：记录**实际**观察到的传输，不编造 HTTP method+path。
- 跨行动者槽位存在；本里程碑不打开第二会话，写入「跨行动者未执行」。
- 失败时只记录已经观察到的内容。

## candidates.jsonl

- `execution_status`：`observed` | `executed` | `not_executed` | `unreachable` | `unsupported` | `uncertain`（这里**没有** `out_of_scope`）
- `scope_status`：`in_scope` | `out_of_scope` | `unresolved`
- 同一 snapshot + 同一发现 → 稳定 `candidate_id`
- `evidence_id` 不可变

## 首发 study（仅通用类型）

领域：**消息发送与状态同步**。

- 范围内：打开已有目标 Surface 并发送一条消息，包括打开它的导航点击。
- 范围外：穷尽导航树、创建容器、容器管理、穷尽私信、话题串、管理后台。
- **不得**把发送入口标为范围外。
- 核心类型永远是 Surface / Control / Journey / Observation。不得把 Room / Channel / Rocket.Chat 当作类型。

## 范围外（禁止在 M4 实现）

- 真实 AgentRunner（M5）
- 人工审定模型 + 四份导出（M6）
- Effect DAG / platform / Broker / Reconciler
- 克隆 `https://github.com/RocketChat/Rocket.Chat` 或任何真实产品仓库
