# M16：官方 dump 把 title 与 aria-label 记为 locator 候选

Will 于 2026-08-22 锁定。本里程碑修正官方 `dumpVisibleControls`：图标按钮的无障碍名可能是私用区字形，节点上已有的 `title` / `aria-label` 必须成为 locator 候选，人类才能批准其中一条，而不是把 `observed.name` 改写成 title。

四套公共接口与六步不变：`SourceProvider` / `ProjectAdapter` / `DiscoveryAdapter` / `AgentRunner`；`detect` / `plan` / `start` / `scan` / `explore` / `execute`。

**不**增加第五套接口。  
**不**改写四接口。  
**不**写入 Channel / Room / Rocket.Chat 类型或选择器。  
**不**在 `packages/` 发明可读的 `name=`。

## 锁定

1. `dumpVisibleControls` 在节点存在 `title` 或 `aria-label` 时写入对应 `locator_candidates`。`observed.name` 仍是无障碍名，即使它是字形。不得把 name 改写成 title。
2. 人类 Binding 可以批准一条 title 或 aria-label（`label`）候选。`execute` / `play` 只等这一条批准 locator。不回退。不在 `packages/` 发明可读 name。
3. 若缺 locator 类型则增加 `title`。`aria-label` 用已有的 `label`。`packages/` 不写 RC 字符串。
4. 四接口不变。不增加第五套接口。
5. 夹具：仅图标、带 `title=Open item` 的按钮可被人类绑定并被 play 点击；`observed.name` 仍是字形或空。

## 契约测试

保持 M0–M14 变绿。`npm test` = vitest + tsc。

- 夹具：explore 后该图标控件有 `title` 候选；`observed.name` 不是 `Open item`
- 人类批准 `{ type: "title", value: "Open item" }` 后 play 点击为 `success`
- `packages/` 不写产品域按钮名
