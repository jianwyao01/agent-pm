# M5：第一版真实 AgentRunner

M5 实现 `AgentRunner.run(task) -> AgentResult` 的**第一版真实 runner**（`DefaultAgentRunner`）。  
它是对**已批准 M4 产物**的事后 classify / prune，不是让 Agent 去探索产品，也不是人工审定模型与四份导出（M6）。

> CI 对仓库内的**双 Surface 微型夹具**做确定性分析，**不**克隆真实产品仓库，**不**需要 LLM API key，**不**需要外网。  
> 产品级 Rocket.Chat 提案只能出现在一次**可信的 RC 运行之后**（操作者 Linux 机器、用户将该仓库标为 trusted 并提供会话）。那不是 CI，也不是本里程碑。  
> LLM 是可选后端，默认关闭；没有显式 key + 显式允许网络时必须走确定性分析。

## 锁定契约

- `AgentRunner.run(task) -> AgentResult`
- Task kind **仅**允许：
  - `classify_features`
  - `build_journeys`
  - `analyze_effects`
  - `prune_candidates`
- **禁止**增加 `guide` / `action` / `explore` 任务 kind。
- M0 `MockAgentRunner` 继续服务合约测试。它不是第二套引擎。  
  替换 Mock 与真实 runner **不得**改动 Source / `start` / Discovery / export 代码。

## 输入与信任

- 输入 = 已批准的 M4 文件 + 只读 workspace。
- workspace：`read_only`
- `write_paths` **只**允许：
  - `runs/<run-id>/proposals/<task-id>.json`
  - `runs/<run-id>/agent-scratch/`
- `inherit_host_credentials: false`
- `load_project_agent_config: false`
- `network: denied_or_explicit`
- `timeout_ms` 必填

Agent **可以**在允许的 `write_paths` 里提出一份 `RunPlan`。  
`start()` **永不**读取该提案，只认人类确认的 `run-plan.yaml`。  
`assertPlanConfirmed` 只作用于官方计划。

## 输出

- 先过 Structural Schema，再过 Semantic Validator（`evidence_ref` 必须存在，candidate ID 保持原样）。
- 无证据边一律拒绝。
- `status`：`success` | `partial` | `failed`
- 每个任务写自己的 `proposals/<task-id>.json`，不是单一的 `agent-result.json`。
- 每个**保留项**用中文至少三句说明：这是什么功能、影响谁、哪些组合重要。
- 删除 / 剪枝的枚举必须留下原因。
- 超时或失败 → `partial` 或 `failed`；不得把「未完成」写成「不存在」；不得修改 `model/`。

## 实现路径

四种任务是对 `candidates.jsonl` + evidence 的**确定性分析**（产品路径，不是 Mock 罐头走查）。  
可选 LLM 后端共用同一接口，但除非显式提供 key **并且**允许网络，否则关闭。测试不依赖 LLM。

真实 runner **不**调用 Discovery `explore` / `execute`，**不**驾驶产品。

## 范围外（禁止在 M5 实现）

- 人工审定模型 + 四份导出（见 [M6.md](M6.md)）
- Effect DAG / Broker / Scheduler / platform
- 让 Agent 探索产品或驱动 Discovery execute
- 克隆 `https://github.com/RocketChat/Rocket.Chat` 或任何真实产品仓库
- 把 Room / Channel / Rocket.Chat 当作核心类型
