# M0：合约与 Mock

M0 只冻结分析器的文件合约、校验器、Mock Agent 和导出函数。  
它**不是** Rocket.Chat（或任何真实产品）规模的验收，也不实现 M1–M6 产品适配器。

## 范围内

- 核心类型：`Surface` / `Control` / `Journey` / `Observation`
- 四接口的 **TypeScript 类型**：`SourceProvider`、`ProjectAdapter`、`DiscoveryAdapter`、`AgentRunner`（Source 实现见 [M1.md](M1.md)；detect/plan 见 [M2.md](M2.md)）
- 各分析文件的 JSON Schema + 语义校验
- `MockAgentRunner`（唯一实现）
- 四个导出函数：`generateProductMap` / `generateDiagrams` / `generateWeb` / `generateTests`
- 消息域 *形状* 的假数据走查（一次发送动作）

## 范围外（禁止在 M0 实现）

- 克隆或抓取任何产品仓库
- 真实 boot / Playwright 探索 / LLM（git/local 快照见 M1；CI 仍不抓取产品仓库）
- Effect DAG、Reconciler、Capability Registry、Worker Protocol、Broker
- 把 GitHub 或聊天产品类型焊进核心
- 对发现结果做静默 Top-N 截断
- 在 `run-plan` 或 `analysis/` 中写入明文密钥

## 启动结果

`StartResult.status`：`success` | `partial` | `failed-runtime`  
只有 `success` 带有可供 `explore` 使用的 `RunningProject`。  
`DiscoveryAdapter.scan` 不依赖 `StartResult`。

## Agent 合约

- 只读 `approved_read_paths`
- 只写 `runs/<run-id>/proposals/<task-id>.json` 与 `runs/<run-id>/agent-scratch/`
- `inherit_host_credentials: false`
- `load_project_agent_config: false`
- workspace `read_only`
- network `denied_or_explicit`
- 返回 `success` | `partial` | `failed`
- 失败不得改 `model/`
- 以接口注入：换真实 runner 不必改 source / boot / discovery / export

## 观察与六列投影

核心只存通用观察：

- `current_surface`
- `other_surface`
- `collection`（subtype `list`）
- `indicator`（subtype `unread`）
- `notification`
- `backend_operation`（`transport`: http | websocket | rpc | event | database | unknown）

六列展示是投影，不是存储模型：本面 / **他面** / 列表 / 未读 / 通知 / 后台。  
未读与通知可以为「未观察到」。至少需要本面 +（他面或列表）+ 后台被观察到。

## 标识

- `evidence_id` 不可变
- `candidate_id` 对同一 snapshot + 同一 discovery 稳定
- `proposal_id` 按 agent task
- `journey_id` 在人工接受时分配，此后稳定；重命名不改 id
- 缺支持 → `stale` / `not_observed`，禁止静默删除

## 二次运行

新的 `runs/<run-id>/`；`model/` 的 keep / reject / rename 存活；覆盖 proposal 不得改写 model；`diff.json` 默认对比同一 study+scope 的上一完成 run。
