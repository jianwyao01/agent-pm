# M1：Source 快照

M1 只实现 `SourceProvider.prepare(source) -> { workspace, snapshot }` 的 **git** 与 **local**。  
这是材料快照，不是产品启动，也不是 Discovery / Agent。

> Rocket.Chat 级的产品仓库抓取是**后续**在操作者机器上的可信/手工运行，**不是 CI**。  
> 单元测试只用临时目录里的微型 git 夹具（`file://` 或本地路径），绝不克隆 `https://github.com/RocketChat/Rocket.Chat`。

## 范围内

- `kind: git`：公共 Git URL。GitHub / GitLab 只是宿主，核心类型永远是 `git`。记录解析后的 commit。
- `kind: local`：若目录是 git checkout，记录 commit + `dirty`；若不是 git（或尚无 commit），记录 `content_digest`，不伪造 commit。
- `kind: archive`：接口保留，实现未交付。`prepare` 返回 `status: "not_shipped"`，而不是「不支持的 source kind」。
- `source.json`：`schema_version` / `kind` / `locator` / `revision`（以及 `snapshot`）。无 `scope`，无 host-specific 类型，不以绝对路径作为长期身份。
- 下游只消费 `Workspace` + `SourceSnapshot`。`source.kind` 不得漏进 boot / discovery。

## 范围外

- 真实 boot / 运行时 Discovery / 真实 LLM Agent
- Effect DAG / 平台 / 产品适配器
- 在 CI 中抓取任何真实产品仓库

## 身份

- git 与「带 commit 的 local」：快照身份 = 同一 commit。因此对同一夹具 `prepare(git)` 与 `prepare(local)` 相等。
- 非 git local：快照身份 = `content_digest`。
- 工作区绝对路径只存在于本次 `Workspace.path`，不写入长期身份。
