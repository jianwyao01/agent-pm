# M14：collection 刮取不得拖死已成功的 play 点击

Will 于 2026-08-22 锁定。本里程碑修正 M9 `readCollection`：成功的 click/type 之后，不得因为 `getByRole('link').nth(N)` 在 SPA 导航中卡在脱离节点上而把 play 打成 `execute_failed`。

四套公共接口与六步不变：`SourceProvider` / `ProjectAdapter` / `DiscoveryAdapter` / `AgentRunner`；`detect` / `plan` / `start` / `scan` / `explore` / `execute`。

**不**增加第五套接口。  
**不**改写四接口。  
**不**写入 Channel / Room / Rocket.Chat 类型或选择器。

## 锁定

1. 成功的 click/type 之后，play 不得因为 `readCollection` 在 `getByRole('link').nth(N)` 上超时而变成 `execute_failed`。
2. collection 仍用 role+name / listitem / link name，不用夹具 CSS。
3. 每条节点有限短超时；跳过已脱离或找不到的节点；限制节点数量，大页不得把 play 拖死。
4. collection 刮取错误是观察缺口，不是人类动作的 `execute_failed`。已用批准 locator 并完成动作时，click/type 保持 `success`。
5. 四接口不变。`packages/` 不写 RC 字符串。不增加第五套接口。
