## confirmEffects

锁定形状：

```
confirmEffects: [{ journey_id, effect_id, evidence_ref, display_value }]
```

`display_value` 可选。有非空值时，该字符串就是 `observation.display_value`（人类点名可见项）。`evidence_ref` 仍必填，且必须存在于本 run。

省略 `display_value` 时，只从 evidence payload 的 `name` / `label` / `item` / `title` / `delta` / `list_after` 推导。不得使用 `payload.text`（常见整页倾倒）。这些键都给不出非空名称则硬失败。

- 只确认已有六列效果与本 run 已有 evidence id
- 必须人类确认
- 禁止 AI 猜测、回退，禁止把 `proposals/` 当 Binding

`applyHumanReview(confirmEffects)`：

- 把该已有槽位的 `observed` 设为 `true`
- `display_value` 优先用人类给出的非空值，否则从上述 payload 键推导
- 把 `evidence_ref` 追加进 `evidence_refs`
- 不得再插入第二行 collection
- 未知 `journey_id` / `effect_id` / 缺失 `evidence_ref` 是硬错误

`hydrateModel` 不得发明 observation。

`generateAll` 在该列写出 `观察到`。

首次证明使用已有 evidence，不在本 PR 做现场 RC play。
